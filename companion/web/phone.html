OTP Bridge

Connect this phone

✓ This phone can reach your computer.

One thing left: tell the phone to pass verification codes on to this address.

Set it up

  1. Tap Add the shortcut. The address is copied for you. Choose Download, then open OTP Bridge from Safari's downloads. It opens in the Shortcuts app.
    Add the shortcut
  2. When it asks for the address, paste, then tap Add Shortcut.
  3. In the Shortcuts app, go to the Automation tab, tap + (or New Automation) and choose Message.
  4. Tap Message Contains, press the space bar once, then tap Done. A single space makes the automation run for every text.
  5. Choose Run Immediately, then tap Next.
  6. Pick OTP Bridge from the list of your shortcuts.

That is the only automation you need. The shortcut looks at each text on the phone and passes it on only if it has a number in it. Your computer then keeps it only if it finds a code. A text without a number never leaves the phone.

A text with no space in it is not picked up. If your codes arrive like that, as some do in Chinese or Japanese, add one more automation and type a word those texts use, such as 验证码, in place of the space.

The first time it runs, iOS may ask whether Shortcuts can find devices on your local network. Choose Allow.

Set it up by hand instead

Use this if the shortcut cannot be added. Tap Copy at the top of this page and do steps 3 to 5 above, but in step 4 type the word code in place of the space. An automation built by hand does not look at the text first, so a space would pass on every text you receive. Then:

  1. Tap New Blank Automation, search for Get Contents of URL and add it.
  2. Tap the address field of that action and paste.
  3. Tap the small arrow next to the address to show more options. Set Method to POST and Request Body to JSON.
  4. Tap Add new field, choose Text, and type message as the key. Tap the value next to it and pick Shortcut Input from the bar above the keyboard.
  5. Tap Done.

Codes that use other words need their own automation: do this again with OTP, verification, passcode or رمز, whichever your banks and apps use.

Already set up? Change the address

Use this when the address at the top of this page is not the one your phone has now, for example after the computer says its address has changed.

  1. Tap Copy at the top of this page.
  2. Open the Shortcuts app and find OTP Bridge among your shortcuts. Tap the three dots on it, or touch and hold it and choose Edit.
  3. In the box named Text, delete the old address and paste.
  4. Tap Done. The automations stay as they are.

If you built the automation by hand, open it in the Automation tab and replace the address in Get Contents of URL.

  1. Tap Copy above.
  2. Install an app that passes incoming SMS on to a web address. The free, open-source SMS to URL Forwarder does exactly this. MacroDroid, Tasker and Automate can do it too.
  3. In the app, add a rule for every sender (usually *), paste the address as the URL and choose POST if it asks for a method.
  4. Leave the body or template as the app suggests. If you have to write it yourself, send the message text, either on its own or as JSON such as {"from":"%from%","text":"%text%"}.
  5. Allow the app to read SMS and to keep running in the background (turn off battery optimisation for it).

If Android refuses the SMS permission and mentions a restricted setting, open Settings, Apps, the forwarding app, tap the three dots at the top, choose Allow restricted settings, and grant the permission again. Android does this for apps that were not installed from the Play Store.

OTP Bridge keeps only messages that contain a verification code. Everything else is dropped the moment it arrives.

Tap Copy at the top of this page, open the forwarding app, and paste the address over the old URL in your rule.
