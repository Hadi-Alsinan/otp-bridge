Set it up

  1. Tap Copy above.
  2. Open the Shortcuts app and go to the Automation tab.
  3. Tap + (or New Automation) and choose Message.
  4. Tap Message Contains, type code, then tap Done.
  5. Choose Run Immediately, then tap Next.
  6. Tap New Blank Automation, search for Get Contents of URL and add it.
  7. Tap the address field of that action and paste.
  8. Tap the small arrow next to the address to show more options. Set Method to POST and Request Body to JSON.
  9. Tap Add new field, choose Text, and type message as the key. Tap the value next to it and pick Shortcut Input from the bar above the keyboard.
  10. Tap Done.

The automation only fires for messages that contain the word you typed. Codes that use other words need their own automation: repeat the steps with OTP, verification, passcode or رمز, whichever your banks and apps use.
