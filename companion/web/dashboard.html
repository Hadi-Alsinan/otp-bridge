1 Add the browser extension

Not connected

The extension shows the code under the box on the website and fills it in when you click it.

  1. Open chrome://extensions in a new tab (in Edge: edge://extensions).
  2. Turn on Developer mode.
  3. Click Load unpacked and choose this folder:
    the "extension" folder inside the OTP Bridge folder
  4. Come back to this page. It connects by itself within a few seconds.

Keep that folder where it is: the browser loads the extension from it every time it starts. Pages that were open before you added the extension need a reload before codes show up on them.

  1. Open about:debugging#/runtime/this-firefox in a new tab.
  2. Click Load Temporary Add-on and choose the file manifest.json inside the extension folder.
  3. Come back to this page. It connects by itself within a few seconds.

Firefox removes temporary add-ons when it closes, so this has to be repeated after restarting Firefox.

There is no Safari version. Safari on a Mac already fills in codes from an iPhone on its own, so use this for the other browsers.

Using a second browser? Open this page there with the private link, then add the extension in that browser too.
